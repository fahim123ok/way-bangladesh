# Project Instructions

## Mandatory (Must Do) — Safety Rule
1. **Always `git commit` a safe checkpoint BEFORE making ANY code changes.**
2. This guarantees we can restore the previous state 100% accurately if
   anything goes wrong.
3. If a change causes a problem, revert using `git checkout` / `git reset`
   back to that checkpoint.

## User Context
- User speaks Bangla — respond in friendly, simple Bangla.
- User is **non-technical** — explain everything in plain, simple, step-by-step
  language. Avoid jargon.

## Project Facts
- App folder: `banglapath-home`
- Server: `node server.js` → http://localhost:5173
- Easy run file for user: `banglapath-home\start.bat`
- Remember to keep `start.bat` paths correct if the folder is renamed.
